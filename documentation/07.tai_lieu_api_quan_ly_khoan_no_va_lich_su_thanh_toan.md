# 1. Tạo khoản nợ

- **Tên:** API tạo khoản nợ
- **Endpoint:** `POST /api/debts`
- **Mô tả:** Tạo khoản nợ cho người dùng đang đăng nhập.

**Request body mẫu**

```json
{
  "lender_name": "Ngân hàng A",
  "debt_type": "PERSONAL",
  "total_amount": 50000000,
  "remaining_amount": 42000000,
  "monthly_payment": 3000000,
  "interest_rate": 12.5,
  "start_date": "2026-01-15",
  "end_date": "2027-06-15",
  "due_day_of_month": 15
}
```

**Response body**

- Thành công — HTTP `201`:

```json
{
  "status": "success",
  "message": "Tạo khoản nợ thành công",
  "data": {
    "id": 12,
    "user_id": 3,
    "lender_name": "Ngân hàng A",
    "debt_type": "PERSONAL",
    "total_amount": "50000000.00",
    "remaining_amount": "42000000.00",
    "monthly_payment": "3000000.00",
    "interest_rate": "12.50",
    "start_date": "2026-01-15",
    "end_date": "2027-06-15",
    "due_day_of_month": 15,
    "status": "ACTIVE"
  }
}
```

- Thất bại — HTTP `400`, dữ liệu không hợp lệ:

```json
{
  "status": "false",
  "code": "INVALID_REQUEST",
  "message": "Dữ liệu gửi lên không hợp lệ",
  "errors": {
    "total_amount": "total_amount phải lớn hơn 0"
  }
}
```
# 2. Lấy danh sách khoản nợ

- **Tên:** API lấy danh sách khoản nợ
- **Endpoint:** `GET /api/debts`
- **Mô tả:** Trả về các khoản nợ của người dùng đang đăng nhập. API hiện chưa hỗ trợ phân trang hoặc lọc query.

**Response body**

- Thành công — HTTP `200`:

```json
{
  "status": "success",
  "data": [
    {
      "id": 12,
      "lender_name": "Ngân hàng A",
      "debt_type": "PERSONAL",
      "total_amount": "50000000.00",
      "remaining_amount": "42000000.00",
      "monthly_payment": "3000000.00",
      "status": "ACTIVE"
    }
  ]
}
```

- Thất bại — HTTP `401` nếu token không hợp lệ; HTTP `500` nếu có lỗi máy chủ.

## 3. Lấy chi tiết khoản nợ

- **Tên:** API lấy chi tiết khoản nợ
- **Endpoint:** `GET /api/debts/:id`
- **Ví dụ:** `GET /api/debts/12`
- **Mô tả:** Trả về khoản nợ có ID tương ứng nếu khoản nợ thuộc người dùng đang đăng nhập.

**Response body**

- Thành công — HTTP `200`: trả object khoản nợ trong `data`, cùng cấu trúc với một phần tử trong API lấy danh sách khoản nợ.
- Thất bại:
  - HTTP `400` nếu ID không hợp lệ.
  - HTTP `404` nếu không tìm thấy khoản nợ hoặc khoản nợ thuộc người dùng khác.
  - HTTP `401` nếu token không hợp lệ.
  - HTTP `500` nếu có lỗi máy chủ.

## 4. Cập nhật khoản nợ

- **Tên:** API cập nhật khoản nợ
- **Endpoint:** `PATCH /api/debts/:id`
- **Ví dụ:** `PATCH /api/debts/12`
- **Mô tả:** Cập nhật một hoặc nhiều trường của khoản nợ. Dư nợ (`remaining_amount`) được cập nhật thông qua API ghi nhận thanh toán, không cập nhật bằng API này.

Các trường được phép cập nhật: `lender_name`, `debt_type`, `total_amount`, `credit_limit`, `monthly_payment`, `interest_rate`, `start_date`, `end_date`, `due_day_of_month`. Các quy tắc giá trị và quan hệ giữa trường giống API tạo khoản nợ. Có thể gửi `end_date: null` để xóa ngày kết thúc. Không gửi body rỗng hoặc trường khác danh sách trên.

**Request body mẫu**

```json
{
  "monthly_payment": 3200000,
  "due_day_of_month": 20
}
```

**Response body**

- Thành công — HTTP `200`:

```json
{
  "status": "success",
  "message": "Cập nhật khoản nợ thành công",
  "data": {
    "id": 12,
    "monthly_payment": "3200000.00",
    "due_day_of_month": 20,
    "status": "ACTIVE"
  }
}
```

- Thất bại:
  - HTTP `400` nếu body hoặc ID không hợp lệ.
  - HTTP `404` nếu không tìm thấy khoản nợ hoặc khoản nợ thuộc người dùng khác.
  - HTTP `401` nếu token không hợp lệ.
  - HTTP `500` nếu có lỗi máy chủ.

## 5. Xóa khoản nợ

- **Tên:** API xóa khoản nợ
- **Endpoint:** `DELETE /api/debts/:id`
- **Ví dụ:** `DELETE /api/debts/12`
- **Mô tả:** Xóa khoản nợ thuộc người dùng đang đăng nhập. Các kỳ thanh toán liên quan cũng bị xóa theo khóa ngoại.

**Response body**

- Thành công — HTTP `200`:

```json
{
  "status": "success",
  "message": "Xóa khoản nợ thành công"
}
```
