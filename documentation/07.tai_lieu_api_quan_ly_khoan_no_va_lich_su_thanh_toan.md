## 1. Tạo khoản nợ

- **Tên:** API tạo khoản nợ
- **Endpoint:** `POST /api/debts`
- **Mô tả:** Tạo khoản nợ cho người dùng đang đăng nhập.
**Request body mẫu**
```json
{
  "lender_name": "Ngân hàng A",
  "debt_type": "PERSONAL",
  "total_amount": 50000000,
  "remaining_amount": 42000000,
  "monthly_payment": 3000000,
  "interest_rate": 12.5,
  "start_date": "2026-01-15",
  "end_date": "2027-06-15",
  "due_day_of_month": 15
}
```
**Response body**
- Thành công — HTTP `201`:
```json
{
  "status": "success",
  "message": "Tạo khoản nợ thành công",
  "data": {
    "user_id": 3,
    "lender_name": "Ngân hàng A",
    "debt_type": "PERSONAL",
    "total_amount": "50000000.00",
    "remaining_amount": "42000000.00",
    "monthly_payment": "3000000.00",
    "interest_rate": "12.50",
    "start_date": "2026-01-15",
    "end_date": "2027-06-15",
    "due_day_of_month": 15,
    "status": "ACTIVE"
  }
}
```
- Thất bại — HTTP `400`, dữ liệu không hợp lệ:
```json
{
  "status": "false",
  "code": "INVALID_REQUEST",
  "message": "Dữ liệu gửi lên không hợp lệ",
  "errors": {
    "total_amount": "total_amount phải lớn hơn 0"
  }
}
```
## 2. Lấy danh sách khoản nợ

- **Tên:** API lấy danh sách khoản nợ
- **Endpoint:** `GET /api/debts/:userid` (có thể dùng `GET /api/debts` để lấy theo ID trong JWT)
- **Ví dụ:** `GET /api/debts/3`
- **Mô tả:** Trả về các khoản nợ thuộc người dùng có ID `userid`. `userid` phải trùng với ID người dùng trong JWT; không thể dùng endpoint này để đọc dữ liệu của người khác.
**Response body**
- Thành công — HTTP `200`:
```json
{
  "status": "success",
  "data": [
    {
      "id": 12,
      "user_id": 3,
      "lender_name": "Ngân hàng A",
      "debt_type": "PERSONAL",
      "total_amount": "50000000.00",
      "remaining_amount": "42000000.00",
      "monthly_payment": "3000000.00",
      "status": "ACTIVE"
    },
    {
      "id": 13,
      "user_id": 3,
      "lender_name": "Ngân hàng B",
      "debt_type": "PERSONAL",
      "total_amount": "50000000.00",
      "remaining_amount": "42000000.00",
      "monthly_payment": "3000000.00",
      "status": "ACTIVE"
    },
    {
      "id": 14,
      "user_id": 3,
      "lender_name": "Ngân hàng C",
      "debt_type": "PERSONAL",
      "total_amount": "50000000.00",
      "remaining_amount": "42000000.00",
      "monthly_payment": "3000000.00",
      "status": "ACTIVE"
    }
  ]
}
```
- Thất bại (HTTP Code `401`): Thiếu token, token không hợp lệ/hết hạn hoặc token không chứa ID người dùng hợp lệ.

    ```json
    {
      "status": "false",
      "message": "Không tìm thấy token xác thực"
    }
    ```
- HTTP `400` nếu mã người dùng không hợp lệ
```json
    {
	  "status": "false",
      "message": "Mã người dùng không hợp lệ"
    }
```
- HTTP `403` nếu mã người dùng không trùng với mã người dùng trong JWT
```json
    {
	  "status": "false",
      "message": "mã người dùng không trùng với mã người dùng trong JWT"
    }
```

## 3. Lấy chi tiết khoản nợ

- **Tên:** API lấy chi tiết khoản nợ
- **Endpoint:** `GET /api/debts/:userid/:id`
- **Ví dụ:** `GET /api/debts/3/12`
- **Mô tả:** Trả về khoản nợ có ID `id` thuộc người dùng `userid`. `userid` phải trùng với ID người dùng trong JWT.
**Response body**
- Thành công — HTTP `200`: trả object khoản nợ trong `data`, cùng cấu trúc với một phần tử trong API lấy danh sách khoản nợ.
- Thất bại:
  - HTTP `400` nếu mã người dùng không hợp lệ.
   ```json
    {
	  "status": "false",
      "message": "Mã người dùng không hợp lệ"
    }
   ```
  - HTTP `404` nếu không tìm thấy khoản nợ hoặc khoản nợ thuộc người dùng khác.
   ```json
    {
	  "status": "false",
      "message": "Khoản nợ không tồn tại"
    }
   ```
 + Thất bại (HTTP Code `401`): Thiếu token, token không hợp lệ/hết hạn hoặc token không chứa ID người dùng hợp lệ.
    ```json
    {
      "status": "false",
      "message": "Không tìm thấy token xác thực"
    }
    ```
  - HTTP `500` nếu có lỗi máy chủ.

## 4. Cập nhật khoản nợ

- **Tên:** API cập nhật khoản nợ
- **Endpoint:** `PATCH /api/debts/:userid`
- **Ví dụ:** `PATCH /api/debts/3`
- **Mô tả:** Cập nhật một hoặc nhiều trường của khoản nợ. Dư nợ được cập nhật thông qua API ghi nhận thanh toán, không cập nhật bằng API này.
**Request body mẫu**
```json
{
  "monthly_payment": 3200000,
  "due_day_of_month": 20
}
```
**Response body**
- Thành công — HTTP `200`:
```json
{
  "status": "success",
  "message": "Cập nhật khoản nợ thành công",
  "data": {
    "userid": 3,
    "monthly_payment": "3200000.00",
    "due_day_of_month": 20,
    "status": "ACTIVE"
  }
}
```
- Thất bại:
 - HTTP `400` nếu mã người dùng không hợp lệ.
   ```json
    {
	  "status": "false",
      "message": "Mã người dùng không hợp lệ"
    }
   ```
  - HTTP `404` nếu không tìm thấy khoản nợ hoặc khoản nợ thuộc người dùng khác.
   ```json
    {
	  "status": "false",
      "message": "Khoản nợ không tồn tại"
    }
   ```
 + Thất bại (HTTP Code `401`): Thiếu token, token không hợp lệ/hết hạn hoặc token không chứa ID người dùng hợp lệ.
    ```json
    {
      "status": "false",
      "message": "Không tìm thấy token xác thực"
    }
    ```

## 5. Xóa khoản nợ

- **Tên:** API xóa khoản nợ
- **Endpoint:** `DELETE /api/debts/:userid`
- **Ví dụ:** `DELETE /api/debts/3`
- **Mô tả:** Xóa khoản nợ thuộc người dùng đang đăng nhập. Các kỳ thanh toán liên quan cũng bị xóa theo khóa ngoại.
**Response body**
- Thành công — HTTP `200`:
```json
{
  "status": "success",
  "message": "Xóa khoản nợ thành công"
}
```

## 6. Tạo kỳ thanh toán

- **Tên:** API tạo kỳ thanh toán
- **Endpoint:** `POST /api/debts/:debtId/payments`
- **Ví dụ:** `POST /api/debts/12/payments`
- **Mô tả:** Xóa khoản nợ thuộc người dùng đang đăng nhập. Các kỳ thanh toán liên quan cũng bị xóa theo khóa ngoại.
```json
{
  "due_date": "2027-02-15",
  "amount_due": 3000000
}
```
**Response body**
- Thành công — HTTP `201`:
```json
{
  "status": "success",
  "message": "Tạo kỳ thanh toán thành công",
  "data": {
    "id": 31,
    "debt_id": 12,
    "due_date": "2027-02-15",
    "payment_date": null,
    "amount_due": "3000000.00",
    "amount_paid": "0.00",
    "is_late": 0,
    "days_late": 0,
    "status": "PENDING"
  }
}
```
- Thất bại:
  - HTTP `400` nếu ID không hợp lệ.
   ```json
    {
	  "status": "false",
      "message": "Mã người dùng không hợp lệ"
    }
   ```
  - HTTP `404` nếu không tìm thấy khoản nợ hoặc khoản nợ thuộc người dùng khác.
   ```json
    {
	  "status": "false",
      "message": "Khoản nợ không tồn tại"
    }
   ```
 + Thất bại (HTTP Code `401`): Thiếu token, token không hợp lệ/hết hạn hoặc token không chứa ID người dùng hợp lệ.
    ```json
    {
      "status": "false",
      "message": "Không tìm thấy token xác thực"
    }
    ```
  - HTTP `409` nếu khoản nợ đã tất toán.
   ```json
    {
      "status": "false",
      "message": "Khoản nợ đã tất toán"
    }
    ```
  - HTTP `409` nếu dư nợ thay đổi trong lúc tạo kỳ và cần tải lại dữ liệu.
   ```json
    {
      "status": "false",
      "message": "Dư nợ thay đổi trong lúc tạo kỳ và cần tải lại dữ liệu"
    }
    ```
  - HTTP `409` nếu tổng kỳ chưa thanh toán vượt dư nợ còn lại.
   ```json
    {
      "status": "false",
      "message": "Tổng kỳ chưa thanh toán vượt dư nợ còn lại"
    }
    ```

**Request body mẫu**

```json
{
  "amount_paid": 1000000
```

   ```json
    {
```
