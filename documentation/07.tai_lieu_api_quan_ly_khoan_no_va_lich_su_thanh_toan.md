# Tài liệu API quản lý khoản nợ và lịch sử thanh toán

# 1. Tạo khoản nợ
- **Tên:** API tạo khoản nợ
- **Endpoint:** `POST /api/debts`
- **Mô tả:** Tạo khoản nợ cho người dùng đang đăng nhập. Hệ thống tự sinh các kỳ thanh toán dựa trên `start_date`, `end_date`, `monthly_payment` và `due_day_of_month`.
- **Respon body**:
```json
{
  "lender_name": "Ngân hàng A",
  "debt_type": "PERSONAL",
  "total_amount": "50000000.00",
  "remaining_amount": "42000000.00",
  "credit_limit": "0.00",
  "monthly_payment": "3000000.00",
  "interest_rate": "12.00",
  "start_date": "2026-11-26",
  "end_date": "2028-11-26",
  "due_day_of_month": 15
}
```
- Thành công — HTTP `201`
```json
{
    "status": "success",
    "message": "Tạo khoản nợ thành công",
    "data": {
        "id": 4,
        "user_id": 1,
        "lender_name": "Ngan hang A",
        "debt_type": "PERSONAL",
        "total_amount": "9000000.00",
        "remaining_amount": "9000.00",
        "credit_limit": "0.00",
        "monthly_payment": "3000000.00",
        "interest_rate": "12.00",
        "start_date": "2026-11-25T17:00:00.000Z",
        "end_date": "2027-03-25T17:00:00.000Z",
        "due_day_of_month": 15,
        "status": "ACTIVE",
        "created_at": "2026-11-26T13:48:12.000Z",
        "updated_at": "2026-11-26T13:48:12.000Z"
    }
}
```
- Thất bại
Dữ liệu quan hệ không hợp lệ:

```json
{
  "status": "false",
  "code": "INVALID_REQUEST",
  "message": "Dữ liệu gửi lên không hợp lệ",
  "errors": {
    "remaining_amount": "remaining_amount không được lớn hơn total_amount",
    "monthly_payment": "monthly_payment phải lớn hơn 0 khi khoản nợ còn dư",
    "end_date": "end_date không được trước start_date"
  }
}
```

# 2. Lấy danh sách khoản nợ

- **Endpoint:** `GET /api/debts`
- **Mô tả:** Trả về các khoản nợ của người dùng đang đăng nhập.
- **Respon body**:
- Thành công — HTTP `201`
```json
{
  "status": "success",
  "data": [
    {
      "id": 1,
      "user_id": 3,
      "lender_name": "Ngân hàng A",
      "debt_type": "PERSONAL",
      "total_amount": "50000000.00",
      "remaining_amount": "42000000.00",
      "monthly_payment": "3000000.00",
      "status": "ACTIVE"
    }
  ]
}
```
# 3. Lấy chi tiết khoản nợ
- **Endpoint:** `GET /api/debts/:id`
- **Mô tả:** Lấy chi tiết một khoản nợ thuộc người dùng đang đăng nhập.
- **Ví dụ:** `GET /api/debts/2`
- Thành công — HTTP `200`

```json
{
  "status": "success",
    "data": {
        "id": 2,
        "user_id": 1,
        "lender_name": "Khoản vay Postman",
        "debt_type": "PERSONAL",
        "total_amount": "9000000.00",
        "remaining_amount": "9000000.00",
        "credit_limit": "0.00",
        "monthly_payment": "3000000.00",
        "interest_rate": "12.00",
        "start_date": "2026-11-25T17:00:00.000Z",
        "end_date": "2027-03-25T17:00:00.000Z",
        "due_day_of_month": 15,
        "status": "ACTIVE",
        "created_at": "2026-11-26T13:46:38.000Z",
        "updated_at": "2026-11-26T13:46:38.000Z"
    }
}
```

- Thất bại

Không tìm thấy hoặc không thuộc người dùng:

```json
{
  "status": "false",
  "message": "Không tìm thấy khoản nợ"
}
```

`id` không hợp lệ:

```json
{
   "status": "false",
    "code": "INVALID_REQUEST",
    "message": "Dữ liệu gửi lên không hợp lệ",
    "errors": {
        "id": "ID khoản nợ không hợp lệ"
    }
  }

```
# 4. Cập nhật khoản nợ
- **Endpoint:** `PATCH /api/debts/:id`
- **Mô tả:** Lấy chi tiết một khoản nợ thuộc người dùng đang đăng nhập.
- **Ví dụ:** `PATCH /api/debts/2`
- **Resquest body**:
```json
{
  "lender_name": "Ngân hàng Phát triển",
  "end_date": "2029-11-26"
}
```
- Thành công — HTTP `200`
```json
{
    "status": "success",
    "message": "Cập nhật khoản nợ thành công",
    "data": {
        "id": 1,
        "user_id": 1,
        "lender_name": "Ngân hàng Phát triển",
        "debt_type": "PERSONAL",
        "total_amount": "9000000.00",
        "remaining_amount": "9000000.00",
        "credit_limit": "0.00",
        "monthly_payment": "3000000.00",
        "interest_rate": "12.00",
        "start_date": "2026-11-25T17:00:00.000Z",
        "end_date": "2029-11-25T17:00:00.000Z",
        "due_day_of_month": 15,
        "status": "ACTIVE",
        "created_at": "2026-11-26T13:45:59.000Z",
        "updated_at": "2026-11-26T13:59:31.000Z"
    }
}
```
