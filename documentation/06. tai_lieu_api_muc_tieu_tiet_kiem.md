# Tài liệu API mục tiêu tiết kiệm

## Mục lục


## Lưu ý: Tất cả các API đều Yêu cầu đăng nhập thành công trước đó. Gửi JWT nhận được từ API đăng nhập qua header `Authorization`, theo kiểu xác thực Bearer.

## 1. Lấy danh sách mục tiêu tiết kiệm
- Tên: API lấy danh sách mục tiêu tiết kiệm
- Endpoint: 
    + GET `/api/savings`
    + GET `/api/savings?page=<số trang>&month=<tháng>$year=<năm>`
    + GET `/api/savings?saving_id=<mã mục tiêu tiết kiệm>`
- Mô tả: API sẽ trả về danh sách mục tiêu tiết kiệm hoặc 1 mục tiêu tiết kiệm cụ thể của người dùng tùy theo tham số `saving_id` có truyền vào hay không.
- Giải thích các tham số còn lại (chỉ hoạt động trong trường hợp lấy danh sách các mục tiêu tiết kiệm):
    + `page`: Số trang cần lấy với mỗi trang là 10 mục, nhằm tránh quá tải truy vấn quá nhiều, có thể bỏ trống để lấy trang đầu tiên
    + `month` & `year`: Tháng và năm thêm mục tiêu tiết kiệm, dùng trong bộ lọc để trả về danh sách các mục tiêu tiết kiệm trong tháng cụ thể. Cần phải cung cấp cả tháng và năm để bộ lọc hoạt động
- **Response body**
    + Thành công:

    ```json
                "target_amount": "100000.00",
    ```

## 2. Thêm mục tiêu tiết kiệm
- Tên: API thêm mục tiêu tiết kiệm
- Endpoint: POST `/api/savings`
- Mô tả: Người dùng nhập vào các trường bắt buộc: tên mục tiêu, số tiền cần đạt được, tiền đóng góp hàng thàng, ngày cần hoàn thành, lãi suất vào cho hệ thống xác nhận. Nếu xác nhận thành công, sẽ ghi nhận vào CSDL mục tiêu tiết kiệm mới, ngược lại, sẽ thông báo thất bại.
- **Request body mẫu**:
```json
{
    "target_amount": 100000,
    "name": "Mục tiêu tháng 11",
    "monthly_contribution": 10000,
    "target_date": "2026-12-01",
    "interest_rate": 10
}
```
- **Response body**:
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã thêm mục tiêu tiết kiệm thành công"
    }
    ```
    + Thất bại:
    ```json
    // Bỏ trống tên mục tiêu tiết kiệm
    {
        "status": "false",
        "message": "Vui lòng nhập tên mục tiêu tiết kiệm"
    }
    ```

    ```json
    // Nhập vào số tiền mục tiêu đạt được không hợp lệ
    {
        "status": "false",
        "message": "Mục tiêu đạt được phải là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    }
    ```

    ```json
    // Nhập vào số tiền đóng hàng tháng không hợp lệ
    {
        "status": "false",
        "message": "Đóng góp hàng tháng phải là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    }
    ```

    ```json
    // Nhập vào số tiền đóng hàng tháng lớn hơn mục tiêu đạt được
    {
        "status": "false",
        "message": "Đóng góp hàng tháng không được lớn hơn mục tiêu đề ra"
    }
    ```

    ```json
    // Nhập vào lãi suất không hợp lệ
    {
        "status": "false",
        "message": "Lãi suất là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    }
    ```

    ```json
    // Nhập vào thời gian không hợp lệ hoặc nhỏ hơn ngày hiện tại
    {
        "status": "false",
        "message": "hời gian hoàn thành mục tiêu không hợp lệ, phải lớn hơn ngày hiện tại"
    }
    ```

## 3. Sửa mục tiêu tiết kiệm
- Tên: API sửa mục tiêu tiết kiệm
- Endpoint: PATCH `/api/savings`
- Mô tả: Người dùng nhập vào các trường bắt buộc: tên mục tiêu, số tiền cần đạt được, tiền đóng góp hàng thàng, ngày cần hoàn thành, lãi suất vào cho hệ thống xác nhận. Nếu xác nhận thành công, sẽ cập nhật lại vào CSDL, ngược lại, sẽ thông báo thất bại. Ngoài ra, hệ thống có thể cập nhật các trường khác như: trạng thái và số tiền đã đóng góp khi người dùng đóng tiền vào mục tiêu hoặc hoàn thành mục tiêu
- **Request body mẫu**:
```json
{
    "saving_id": 1,
    "target_amount": 100000,
    "name": "Mục tiêu tháng 11",
    "monthly_contribution": 10000,
    "target_date": "2026-12-01",
    "interest_rate": 10,
    "status": "CANCELLED",
    "current_amount": 30000
}
```
- **Response body**:
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã sửa mục tiêu tiết kiệm thành công"
    }
    ```
    + Thất bại:
    ```json
    // Request body không chứa bất kỳ trường nào
    {
        "status": "false",
        "message": "Ít nhất một trường hợp lệ là bắt buộc"
    }
    ```

    ```json
    // Request body chứa các tên trường không hợp lệ
    {
        "status": "false",
        "message": "Request body chứa các trường không hợp lệ"
    }
    ```

    ```json
    // Nhập vào id mục tiêu không hợp lệ
    {
        "status": "false",
        "message": "Id mục tiêu tiết kiệm không hợp lệ"
    }
    ```

    ```json
    // Nhập vào id của mục tiêu không tồn tại
    {
        "status": "false",
        "message": "Mục tiêu tiết kiệm không tồn tại"
    }
    ```

    ```json
    // Bỏ trống tên mục tiêu tiết kiệm
    {
        "status": "false",
        "message": "Vui lòng nhập tên mục tiêu tiết kiệm"
    }
    ```

    ```json
    // Nhập vào số tiền mục tiêu đạt được không hợp lệ
    {
        "status": "false",
        "message": "Mục tiêu đạt được phải là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    }
    ```

    ```json
    // Nhập vào số tiền đóng hàng tháng không hợp lệ
    {
        "status": "false",
        "message": "Đóng góp hàng tháng phải là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    ```

    ```json
    // Nhập vào lãi suất không hợp lệ

        "message": "Lãi suất là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    ```

## 4. Xóa mục tiêu tiết kiệm
- Tên: API xóa mục tiêu tiết kiệm
- Endpoint: DELETE `/api/savings`
- Mô tả: API nhận trường `saving_id` của người dùng truyền vào để tiến hành xóa mục tiêu tiết kiệm. Nếu id hợp lệ, mục tiêu tiết kiệm với id đó sẽ được xóa trên CSDL, ngược lại, thông báo thất bại
- **Request body**:
```json
{
    "saving_id": 1
}
```
- **Response body**
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã xóa mục tiêu tiết kiệm thành công"
    }
    ```

    + Thất bại:
    ```json
    // Id mục tiêu tiết kiệm truyền vào là 1 id không hợp hợp lệ
    {
        "status": "false",
        "message": "Id mục tiêu tiết kiệm không hợp lệ"
    }
    ```

    ```json
    // mục tiêu tiết kiệm không tồn tại
    {
        "status": "false",
        "message": "Xóa mục tiêu tiết kiệm thất bại!!"
    }
    ```
