## 1. Thiết lập hồ sơ cá nhân
### 1.1. Lấy hồ sơ cá nhân
- Tên: API lấy hồ sơ cá nhân
- Endpoint: GET `/api/users/me/profile`
- Mô tả: Trả về hồ sơ của người dùng đang đăng nhập. ID người dùng được lấy từ JWT, client không cần gửi ID trên URL.
- `Content-Type: application/json`
- Yêu cầu đăng nhập thành công trước đó. Gửi JWT nhận được từ API đăng nhập qua header `Authorization`, theo kiểu xác thực Bearer.
- Response body:
    + Thành công (HTTP Code `200`):

    ```json
    {
	  "status":"success",
	  "message":"Lấy hồ sơ cá nhân thành công",
      "data": {
        "id": 1,
        "full_name": "Nguyen Van A",
        "date_of_birth": "1990-05-15",
        "occupation": "Nhân viên văn phòng",
        "number_of_dependents": 1,
        "monthly_income": "20000000.00",
        "created_at": "2026-10-29T10:00:00.000Z",
        "updated_at": "2026-10-29T10:00:00.000Z"
      }
    }
    ```

    + Thất bại (HTTP Code `401`): Thiếu token, token không hợp lệ/hết hạn hoặc token không chứa ID người dùng hợp lệ.

    ```json
    {
      "status": "false",
      "message": "Không tìm thấy token xác thực"
    }
    ```

    + Thất bại (HTTP Code `404`): Không tìm thấy người dùng.

    ```json
    {
      "message": "Người dùng không tồn tại"
    }
    ```

### 1.2. Cập nhật hồ sơ cá nhân
- Tên: API cập nhật hồ sơ cá nhân
- Endpoint: PATCH `/api/users/me/profile`
- Mô tả: Cập nhật một hoặc nhiều thông tin ở hồ sơ người dùng đang đăng nhập. ID người dùng được lấy từ JWT, client không cần gửi ID trên URL.
- `Content-Type: application/json`
- Yêu cầu đăng nhập thành công trước đó. Gửi JWT nhận được từ API đăng nhập qua header `Authorization`, theo kiểu xác thực Bearer.
- Có thể chỉ gửi những trường cần cập nhật; không gửi `id` và không bọc dữ liệu trong `data`.
- `monthly_income` được gửi dưới dạng chuỗi thập phân không âm, tối đa 13 chữ số trước dấu thập phân và 2 chữ số sau dấu thập phân, ví dụ `"15000000.00"`.
- **Request body mẫu**
    ```json
    {
        "full_name": "Nguyen Van A",
        "date_of_birth": "2000-09-02",
        "occupation": "Nhân viên văn phòng",
        "number_of_dependents": 1,
        "monthly_income": "15000000.00"
    }
    ```

- **Response body**
    + Thành công (HTTP Code `200`):

    ```json
    {
	  "status":"success",
      "message": "Hồ sơ đã được cập nhật thành công",
      "data": {
        "id": 1,
        "full_name": "Nguyen Van A",
        "date_of_birth": "2000-09-02",
        "occupation": "Nhân viên văn phòng",
        "number_of_dependents": 1,
        "monthly_income": "15000000.00",
        "created_at": "2026-10-29T10:00:00.000Z",
        "updated_at": "2026-10-29T10:00:00.000Z"
      }
    }
    ```

    + Thất bại (HTTP Code `400`): Body rỗng, có trường không hỗ trợ hoặc giá trị sai định dạng (ví dụ `date_of_birth` không theo `YYYY-MM-DD`, `monthly_income` âm/sai kiểu hoặc `number_of_dependents` không phải số nguyên từ 0 đến 255).

    ```json
    {
	  "status": "false",	
      "message": "date_of_birth phải là một chuỗi ngày hợp lệ theo định dạng YYYY-MM-DD hoặc null",
    }
    ```

    + Thất bại (HTTP Code `401`): Thiếu token, token không hợp lệ/hết hạn hoặc token không chứa ID người dùng hợp lệ.

    ```json
    {
      "status": "false",
      "message": "Không tìm thấy token xác thực"
    }
    ```

    + Thất bại (HTTP Code `404`): Không tìm thấy người dùng.

    ```json
    {
	  "status": "false",
      "message": "Người dùng không tồn tại"
    }
