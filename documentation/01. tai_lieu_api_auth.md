## 1. Đăng nhập
- Tên: API Đăng nhập
- Endpoint: POST `/api/auth/login`
- Mô tả: Nhận tên đăng nhập (SĐT, Email) và mật khẩu từ người dùng, tương tác với CSDL để xác thực. Nếu thành công thì trả về token cho những lần xác thực sau, ngược lại báo lỗi tương ứng cho người dùng.
- `Content-type: application/json `
- **Request body mẫu**:

```json
{
	"username": "0123456789",
	"password": "User123456@"
}
```

- Respond body:
```json
// Thành công (HTTP Code `200`)
{
	"status": "success",
	"message": "Đăng nhập thành công",
	"token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

```json
// Trường hợp bỏ trống username, mật khẩu (HTTP Code `400`)
{
	"status":"false",
	"message":"Dữ liệu đầu vào không hợp lệ",
	"errors":
	{	
		"username": "Tên đăng nhập không được để trống",
		"password": "Mật khẩu không được để trống"
	}
}
```

```json
// Trường hợp sai mật khẩu hoặc username (HTTP Code `400`)
{
	"status": "false",
	"message": "Tên đăng nhập hoặc mật khẩu không chính xác"
}

```

## 2. Đăng ký
- Tên: API Đăng ký
- Endpoint: POST `/api/auth/register`
- Mô tả: Nhận tên đăng nhập (SĐT, EMail), họ tên và mật khẩu từ người dùng, tương tác với CSDL để kiểm tra trùng tài khoản (SĐT, Email). Nếu thành công thì lưu thông tin tài khoản vào CSDL, ngược lại báo lỗi tương ứng cho người dùng
- `Content-type: application/json`
- **Request body mẫu**
```json
{
	"full_name":"user1",
	"email":"user1@gmail.com",
	"phone":"0123456789",
	"password":"User123456@"
}

```

- **Response body**:
```json
// Thành công (HTTP code: `201`)
{
	"status": "success",
	"message": "Đăng ký tài khoản thành công"
}
```

```json
// Sai dữ liệu đầu vào (HTTP code: `400`):
// Dấu / xác định một trường hợp lỗi có thể
{
	"status":"false",
	"message":"Dữ liệu đầu vào không hợp lệ",
	"errors":
{	
	"full_name": "Họ và tên không được để trống / Họ và tên không được quá 100 ký tự",
	"email":"Email không được để trống / Định dạng Email không hợp lệ (ví dụ: name@example.com)",
	"phone":"Số điện thoại không được để trống / Số điện thoại không đúng định dạng (gồm 10 chữ số)",
	"password": "Mật khẩu không được để trống / Mật khẩu phải có tối thiểu 8 ký tự / Mật khẩu phải chứa cả chữ hoa, chữ thường và số (ví dụ: Abc123456)"
	}
}
```

```json
// Tài khoản đã tồn tại (HTTP code: `409`):
{
	"status": "false",
	"message": "Số điện thoại hoặc Email này đã được sử dụng"
}
```

## 3. Cấp OTP cho người dùng
- Tên: API cấp OTP gửi mail cho người dùng
- Endpoint: POST `/api/auth/get_otp`
- Mô tả: Nhận email của người dùng để gửi vào email mã xác nhận OTP dùng 1 lần, cập nhật lên CSDL mã OTP và thời gian hết hạn là 5 phút. Nếu email tồn tại thì mới gửi OTP, còn lại thì sẽ thông báo thất bại
- `Content-type: application/json`
- **Request body mẫu**
```json
{
	"email": "user@email.com"
}
```

- **Response body**:
```json
// Trường hợp xác nhận email thành công (HTTP code: 200)
{ 
	"status": "success",
	"message": "Đã sinh ra mã OTP"
}
```

```json
// Trường hợp email chưa được đăng ký trong bất kỳ tài khoản nào (HTTP code: 401)
{ 
	"status": "false",
	"message": "Email này chưa được liên kết với tài khoản nào"
}
```

```json
// Trường hợp bỏ trống email (HTTP code: 401)
{ 
	"status": "false",
	"message": "Vui lòng nhập email"
}
```

## 4. Reset mật khẩu của người dùng
- Tên: API reset mật khẩu của người dùng
- Endpoint: POST `/api/auth/reset_password`
- Mô tả: Nhận email, mật khẩu, mật khẩu nhập lại, mã OTP đã được gửi qua email của người dùng để đối chiếu. Nếu đối chiều khớp thông tin thì tiến hành đổi mật khẩu người dùng và thông báo thành công, ngược lại thì sẽ thông báo thất bại
- `Content-type: application/json`
- **Request body mẫu**
```json
{
	"email": "user@email.com",
	"password": "123456",
	"confirm_password": "123456",
	"otp": "999999"
}
```

- **Response body**:
```json
// Trường hợp xác nhận đổi mật khẩu thành công (HTTP code: 200)
{ 
	"status": "success",
	"message": "Đã đổi mật khẩu thành công!!"
}
```

```json
// Trường hợp bỏ trống email (HTTP code: 401)
{ 
	"status": "false",
	"message": "Vui lòng nhập email"
}
```

```json
// Trường hợp bỏ trống mật khẩu hoặc mật khẩu nhập lại không khớp (HTTP code: 401)
{ 
	"status": "false",
	"message": "Mật khẩu không khớp"
}
```

```json
// Trường hợp email chưa được đăng ký trong bất kỳ tài khoản nào (HTTP code: 401)
{ 
	"status": "false",
	"message": "Email này chưa được liên kết với tài khoản nào"
}
```

```json
// Trường hợp bỏ trống OTP, OTP không hợp lệ hoặc đã hết hạn sau 5 phút (HTTP code: 401)
{ 
	"status": "false",
	"message": "OTP của bạn đã hết hạn hoặc không hợp lệ"
}
```
