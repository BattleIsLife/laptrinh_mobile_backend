## 1. Quản lý tài khoản tín dụng
### 1.1. Lấy thông tin tài khoản tín dụng
- Tên: API lấy thông tin tài khoản tín dụng của user
- Endpoint: 
    + GET `/api/credit_accounts`
    + GET `/api/credit_accounts?account_id=<Mã tài khoản>`
- Mô tả: API giúp trả về thông tin của 1 tài khoản cụ thể hoặc 1 danh sách tài khoản tín dụng của người dùng sau khi đăng nhập tùy theo có truyền tham số `account_id` vào đường dẫn hay không. Nếu khớp, hệ thống sẽ trả về 1 tài khoản cụ thể/danh sách các tài khoản tín dụng, ngược lại, hệ thống báo lỗi không tìm thấy.
- **Các header cần phải truyền vào trước khi gửi**:
    + `Content-type: application/json`
    + `authorization: Bearer <token>`
- **Response body**
    + Thành công:
    ```json
    // Trường hợp trả về danh sách các tài khoản của người dùng (Không đi kèm tham số)
    {
        "status": "true",
        "data": [
            {
                "id": 1,
                "user_id": 1,
                "account_type": "CREDIT_CARD",
                "bank_name": "Ngân hàng Giả tưởng Việt Nam",
                "credit_limit": "700000.00",
                "current_balance": "100000.00",
                "opened_date": "2026-11-03T17:00:00.000Z",
                "closed_date": null,
                "status": "ACTIVE"
            },
            {
                "id": 2,
                "user_id": 1,
                "account_type": "CREDIT_CARD",
                "bank_name": "Ngân hàng DEF",
                "credit_limit": "5000000.00",
                "current_balance": "200000.00",
                "opened_date": "2026-11-03T17:00:00.000Z",
                "closed_date": null,
                "status": "ACTIVE"
            },
            ...
        ]
    }
    ```

    ```json
    // Trường hợp trả về 1 tài khoản cụ thể (Có đi kèm tham số. Ví dụ: ?account_id=1)
    {
        "status": "true",
        "data": {
            "id": 1,
            "user_id": 1,
            "account_type": "CREDIT_CARD",
            "bank_name": "Ngân hàng Giả tưởng Việt Nam",
            "credit_limit": "700000.00",
            "current_balance": "100000.00",
            "opened_date": "2026-11-03T17:00:00.000Z",
            "closed_date": null,
            "status": "ACTIVE"
        }
    }
    ```

    + Thất bại:
     ```json
    // Token xác thực bị bỏ trống hoặc không hợp lệ
    {
        "status": "false",
        "message": "Không tìm thấy token xác thực"
    }
    ```

    ```json
    // Khi không tìm được danh sách tài khoản hoặc tài khoản cụ thể cần tìm (sai cả user_id và account_id)
    {
        "status": "false",
        "message": "Không tìm thấy tài khoản"
    }
    ```

### 1.2. Thêm tài khoản tín dụng
- Tên API: API thêm tài khoản tín dụng
- Endpoint: POST `/api/credit_accounts`
- Mô tả: Người dùng truyền vào các thông tin như: loại tài khoản, tên ngân hàng, số dư tài khoản và hạn mức tài khoản. Nếu thông tin hợp lệ, hệ thống sẽ thêm tài khoản tín dụng mới với những thông tin kể trên, ngoài ra, tài khoản mởi sẽ mặc định trạng thái là `ACTIVE` với ngày thêm là thời điểm thêm thành công, ngược lại, hệ thống sẽ thông báo lỗi.
- **Các header cần phải truyền vào trước khi gửi**:
    + `Content-type: application/json`
    + `authorization: Bearer <token>`
- **Request body mẫu**:
```json
{
    "account_type": "CREDIT_CARD",
    "bank_name": "Ngân hàng ABC",
    "credit_limit": 5000000,
    "current_balance": 200000
}
```
- **Response body**
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã thêm tài khoản tín dụng thành công"
    }
    ```
    + Thất bại:
    ```json
    // Token xác thực bị bỏ trống hoặc không hợp lệ
    {
        "status": "false",
        "message": "Không tìm thấy token xác thực"
    }
    ```

    ```json
    // Bỏ trống hoặc truyền vào loại tài khoản không hợp lệ
    {
        "status": "false",
        "message": "Loại tài khoản không hợp lệ, phải là CREDIT_CARD hoặc OVERDRAFT"
    }
    ```

    ```json
    // Cố tình truyền vào các trường không hợp lệ
    {
        "status": "false",
        "message": "Request body chứa các trường không hợp lệ"
    }
    ```

    ```json
    // Bỏ trống tên ngân hàng
    {
        "status": "false",
        "message": "Vui lòng nhập tên ngân hàng"
    }   
    ```

    ```json
    // Bỏ trống hoặc nhập vào hạn mức tín dụng không hợp lệ
    {
        "status": "false",
        "message": "Hạn mức tín dụng phải là 1 số thập phân không âm, tối đa 2 chữ số sau dấu phảy"
    }
    ```

    ```json
    // Bỏ trống hoặc nhập vào số dư tài khoản không hợp lệ
    {
        "status": "false",
        "message": "Số dư tài khoản phải là 1 số thập phân không âm, tối đa 2 chữ số sau dấu phảy"
    }
    ```

### 1.3. Cập nhật thông tin tài khoản tín dụng
- Tên API: API cập nhật thông tin tài khoản tín dụng
- Endpoint: PATCH `/api/credit_accounts`
- Mô tả: Ngoài mã tài khoản là bắt buộc, Người dùng truyền vào ít nhất 1 trong các thông tin như: loại tài khoản, tên ngân hàng, số dư tài khoản và hạn mức tài khoản. Nếu thông tin hợp lệ, hệ thống cập nhật lại thông tin tài khoản với mã đã truyền vào.Ngược lại, hệ thống sẽ thông báo lỗi.
- **Các header cần phải truyền vào trước khi gửi**:
    + `Content-type: application/json`
    + `authorization: Bearer <token>`
- **Request body mẫu**:
```json
{
    "account_id": 1,
    "account_type": "CREDIT_CARD",
    "bank_name": "Ngân hàng ABC",
    "credit_limit": 5000000,
    "current_balance": 200000
}
```
- **Response body**
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã cập nhật tài khoản tín dụng thành công"
    }
    ```
    + Thất bại:
    ```json
    // Token xác thực bị bỏ trống hoặc không hợp lệ
    {
        "status": "false",
        "message": "Không tìm thấy token xác thực"
    }
    ```

    ```json
    // Bỏ trống mã tài khoản tín dụng hoặc nhập vào 1 ký tự không hợp lệ
    {
        "status": "false",
        "message": "Id tài khoản không hợp lệ"
    }
    ```

    ```json
    // Gọi đến id tài khoản không tồn tại
    {
        "status": "false",
        "message": "Không tìm thấy tài khoản"
    }
    ```

    ```json
    // Truyền chuỗi rỗng vào loại tài khoản
    {
        "status": "false",
        "message": "Vui lòng nhập loại tài khoản"
    }
    ```

    ```json
    // Truyền chuỗi rỗng vào tên ngân hàng
    {
        "status": "false",
        "message": "Vui lòng nhập tên ngân hàng"
    }   
    ```

    ```json
    // Truyền chuỗi rỗng hoặc nhập vào hạn mức tín dụng không hợp lệ
    {
        "status": "false",
        "message": "Hạn mức tín dụng phải là 1 số thập phân không âm, tối đa 2 chữ số sau dấu phảy"
    }
    ```

    ```json
    // Truyền chuỗi rỗng hoặc nhập vào số dư tài khoản không hợp lệ
    {
        "status": "false",
        "message": "Số dư tài khoản phải là 1 số thập phân không âm, tối đa 2 chữ số sau dấu phảy"
    }
    ```

### 1.4. Đóng tài khoản tín dụng
- Tên API: API đóng tài khoản tín dụng
- Endpoint: DELETE `/api/credit_accounts`
- Mô tả: Người dùng truyền vào id tài khoản tín dụng cần đóng. Hệ thống sẽ xác minh tài khoản đó tồn tại hoặc thuộc về người dùng đó hay không. Nếu hợp lệ, hệ thống sẽ chuyển trạng thái của tài khoản tín dụng sang trạng thái `CLOSED`. Ngược lại, hệ thống sẽ thông báo lỗi.
- **Các header cần phải truyền vào trước khi gửi**:
    + `Content-type: application/json`
    + `authorization: Bearer <token>`
- **Request body mẫu**:
```json
{
    "account_id": 1,
}
```
- **Response body**
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã đóng tài khoản tín dụng thành công"
    }
    ```
    + Thất bại:
    ```json
    // Token xác thực bị bỏ trống hoặc không hợp lệ
    {
        "status": "false",
        "message": "Không tìm thấy token xác thực"
    }
    ```
    ```json
    // Gọi đến id tài khoản không tồn tại hoặc không phải tài khoản của mình
    {
        "status": "false",
        "message": "Không tìm thấy tài khoản"
    }
    ```
