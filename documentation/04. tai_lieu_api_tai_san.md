## 1. Lấy danh sách tài sản
- Tên: API lấy danh sách tài sản
- Endpoint: 
    + GET `/api/assets`
    + GET `/api/assets?page=<số trang>&month=<tháng>$year=<năm>`
    + GET `/api/assets?asset_id=<mã tài sản>`
- Mô tả: API sẽ trả về danh sách tài sản hoặc 1 tài sản cụ thể của người dùng tùy theo tham số `asset_id` có truyền vào hay không.
- Giải thích các tham số còn lại (chỉ hoạt động trong trường hợp lấy danh sách các tài sản):
    + `page`: Số trang cần lấy với mỗi trang là 10 mục, nhằm tránh quá tải truy vấn quá nhiều, có thể bỏ trống để lấy toàn bộ
    + `month` & `year`: Tháng và năm thêm tài sản, dùng trong bộ lọc để trả về danh sách các tài sản trong tháng cụ thể. Cần phải cung cấp cả tháng và năm để bộ lọc hoạt động
- **Response body**
    + Thành công:
    ```json
    // Trả về danh sách tài sản
    {
        "status": "success",
        "data": [
            {
                "id": 1,
                "user_id": 1,
                "asset_type": "OTHER",
                "name": "Tài sản 1",
                "current_value": "200000000.00",
                "created_at": "2026-11-10T09:47:40.000Z",
                "updated_at": "2026-11-10T10:23:57.000Z"
            },
            {
                "id": 2,
                "user_id": 1,
                "asset_type": "OTHER",
                "name": "Tài sản 2",
                "current_value": "100000000.00",
                "created_at": "2026-11-11T09:12:22.000Z",
                "updated_at": "2026-11-11T09:12:22.000Z"
            }
        ]
    }
    ```

    ```json
    // Trả về 1 tài sản duy nhất
    {
        "status": "success",
        "data": [
            {
                "id": 1,
                "user_id": 1,

            },
        ]
    }
    ```

    + Thất bại:
    ```json
    {
        "status": "false",
        "message": "Không tìm thấy dữ liệu!"
    }
    ```

## 2. Thêm tài sản
- Tên: API thêm tài sản
- Endpoint: POST `/api/assets`
- Mô tả: Người dùng nhập vào các trường bắt buộc: loại tài sản, tên tài sản và giá trị hiện tại của tài sản vào cho hệ thống xác nhận. Nếu xác nhận thành công, sẽ ghi nhận vào CSDL tài sản mới, ngược lại, sẽ thông báo thất bại.
- **Request body mẫu**:
```json
{
    "asset_type": "VEHICLE",
    "name": "Lamborghini",
    "current_value": 100000000
}
```
- **Response body**:
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã thêm tài sản thành công"
    }
    ```
    + Thất bại:
    ```json
    // Bỏ trống hoặc chọn loại tài sản không hợp lệ
    {
        "status": "false",
        "message": "Loại tài sản không hợp lệ, phải là 'REAL_ESTATE', 'VEHICLE', 'GOLD', 'STOCK', 'CASH' hoặc 'OTHER'"
    }
    ```

    ```json
    // Bỏ trống tên tài sản
    {
        "status": "false",
        "message": "Vui lòng nhập tên tài sản"
    }
    ```

    ```json
    // Nhập vào giá trị tài sản không hợp lệ
    {
        "status": "false",
        "message": "Giá trị hiện tại phải là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    }
    ```

## 3. Sửa tài sản
- Tên: API sửa tài sản
- Endpoint: PATCH `/api/assets`
- Mô tả: Người dùng nhập vào mã tài sản, kèm theo ít nhất 1 trong các trường hợp lệ: loại tài sản, tên tài sản và giá trị hiện tại của tài sản vào cho hệ thống xác nhận. Nếu xác nhận thành công, hệ thống sẽ cập nhật tài sản vào CSDL, ngược lại, sẽ thông báo thất bại.
- **Request body mẫu**:
```json
{
    "asset_id": 1,
    "asset_type": "VEHICLE",
    "name": "Lamborghini",
    "current_value": 100000000
}
```
- **Response body**:
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Ít nhất một trường hợp lệ là bắt buộc"
    }
    ```
    + Thất bại:
    ```json
    // Request body không chứa bất kỳ trường nào
    {
        "status": "false",
        "message": "Request body chứa các trường không hợp lệ"
    }
    ```

    ```json
    // Request body chứa các tên trường không hợp lệ
    {
        "status": "false",
        "message": "Request body chứa các trường không hợp lệ"
    }
    ```

    ```json
    // Nhập vào chuỗi rỗng hoặc loại tài sản không hợp lệ
    {
        "status": "false",
        "message": "Loại tài sản không hợp lệ, phải là 'REAL_ESTATE', 'VEHICLE', 'GOLD', 'STOCK', 'CASH' hoặc 'OTHER'"
    }
    ```

    ```json
    // Nhập chuỗi rỗng vào tên tài sản
    {
        "status": "false",
        "message": "Vui lòng nhập tên tài sản"
    }
    ```

    ```json
    // Nhập chuỗi rỗng hoặc giá trị không hợp lệ vào giá trị tài sản
    {
        "status": "false",
        "message": "Giá trị hiện tại phải là 1 số thập phân dương, tối đa 2 chữ số sau dấu phảy"
    }
    ```

## 4. Xóa tài sản
- Tên: API lấy danh sách tài sản
- Endpoint: DELETE `/api/assets`
- Mô tả: API nhận trường `asset_id` của người dùng truyền vào để tiến hành xóa tài sản. Nếu id hợp lệ, tài sản với id đó sẽ được xóa trên CSDL, ngược lại, thông báo thất bại
- **Request body**:
```json
{
    "asset_id": 1
}
```
- **Response body**
    + Thành công:
    ```json
    {
        "status": "success",
        "message": "Đã xóa tài sản thành công"
    }
    ```

    + Thất bại:
    ```json
    // Id tài sản truyền vào là 1 id không hợp hợp lệ
    {
        "status": "false",
        "message": "Id tài sản không hợp lệ"
    }
    ```

    ```json
    // Tài sản không tồn tại
    {
        "status": "false",
        "message": "Xóa tài sản thất bại!!"
    }
    ```
